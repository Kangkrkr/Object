### **1. Base Case**: 기본적인 협력 구현
가장 기본적인 객체 간 협력 구현입니다. 객체들은 각자의 역할을 분리하지만, 다른 객체의 정보를 직접 탐색하거나 필요한 자료를 직접 가져오는 형태로 협력합니다. 이 방식은 객체 간의 **결합도(Coupling)**가 높아질 수 있습니다.

#### Base Case의 문제점:
- **결합도가 높다**: `Order` 클래스가 `Cart`와 `Product`의 내부 정보(상품 가격 등)에 직접적으로 접근합니다.
- 객체에 필요한 행위를 해당 객체가 아닌 다른 객체에서 실행하므로 **책임이 적절하지 않음**.
